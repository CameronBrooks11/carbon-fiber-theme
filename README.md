# Carbon Fiber Theme

A refined dark UI theme featuring carbon-fiber texture and cohesive design tokens.
It began as the theme of [FiberPath](https://github.com/fiberpath/fiberpath).

[Live demo](https://cameronbrooks11.github.io/carbon-fiber-theme/): `index.html`, showing the
background, a card, both buttons and a link.

## Usage

Include `style.css` in your HTML:

```html
<link rel="stylesheet" href="style.css" />
```
